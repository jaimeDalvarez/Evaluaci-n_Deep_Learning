## Descripción del Proyecto
Este proyecto implementa una red neuronal tipo Perceptrón Multicapa (MLP) utilizando **TensorFlow/Keras** para realizar una **clasificación multietiqueta**. El modelo predice simultáneamente tres intereses de los usuarios de forma binaria (`interes_tecnologia`, `interes_moda`, `interes_deportes`), lo que permite que una persona pueda tener cero, uno o varios intereses al mismo tiempo.
